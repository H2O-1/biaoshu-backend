# 项目管理专家评审功能拆分

> 目标：在 `AI审查完成` 后新增项目级专家评审流程。专家按每个投标包下的 `biz_requirement_item` 逐条评审；项目结束后自动清理临时专家账号，并保留评审数据和导出能力。

## 1. 功能范围

### 1.1 本期要做

- 项目详情页新增“专家评测”标签页。
- 项目状态为 `AI审查完成` 时，显示“推送专家评审”入口。
- 项目状态为 `专家评审中` 时，显示“追加推送专家”入口。
- 项目状态为 `专家评审完成` 时，不再显示推送 / 追加入口。
- 支持先维护专家名单：通过专家姓名创建临时专家账号，并生成随机密码。
- 专家登录后直接进入当前唯一评审任务详情页，不展示任务列表。
- 专家评审对象仅为 AI 审查中“待人工确认”的条目。
- 资格要求支持：
  - 合格 / 不合格
  - 填写建议
  - 上传图片附件
  - 不合格时可确认是否废标
- 评分项支持：
  - 填分
  - 填写建议
  - 上传图片附件
- 支持按投标单位切换评审。
- 支持管理员对“待确认废标”做确认或继续展示。
- 支持专家评测结果统计、对比、排行、导出。
- 支持截止时间自动提交。
- 支持项目删除时级联清理专家任务和临时账号。

### 1.2 本期不做

- 不做法律库。
- 不做法律风险识别。
- 不做人工复核的多级审批链。
- 不做专家之间互相评论。
- 不做 OCR。
- 不做手工导入历史专家账号。
- 不做独立任务列表页给专家选择。

## 2. 已确认业务规则

- 专家评审的对象是 `AI审查` 后仍需人工确认的 `biz_requirement_item`。
- 项目可以有多个专家。
- 专家名单先创建，正式推送再进入评审流程。
- 先创建专家，再推送任务；推送时只负责正式启动评审，不再新建专家账号。
- 追加专家只传姓名，后端自动创建账号，备注和截止时间沿用首次推送。
- 临时专家密码只在创建时返回一次，后续不再明文返回。
- 某个专家评完后，该专家再次进入同一项目时只能只读，不能修改。
- 当项目下所有专家都评审完成后，专家账号不允许再登录。
- 项目删除时，项目下相关临时专家账号一起删除。
- 项目结束有两个触发条件：
  - 所有专家都已完成评审
  - 到达评审截止时间
- 截止时间到达后，系统自动提交：
  - 已填写单位按当前内容提交
  - 未填写单位生成空评分表并标记逾期提交
- 项目结束后：
  - 项目状态变为 `专家评审完成`
  - 保留评审任务、评分表、附件数据
  - 不允许再推送 / 追加专家
  - 不允许再修改评分
  - 仅允许处理此前已经产生的待确认废标
- “继续展示”按 **项目 + 公司** 永久生效。
- 某项目下某公司一旦选择“继续展示”，后续新的废标建议不再弹窗。
- 废标只影响当前项目，不影响其他项目。
- 项目一旦进入专家评审，AI 审查结果即锁定，不随后续变化。
- 专家评审完成后，项目下招标文件与投标文件的上传、替换、删除、重新解析、重新审查全部锁定。

## 3. 推荐业务流程

1. 项目完成 `AI审查`。
2. 招标方在项目详情页先添加专家，后端按专家姓名创建临时专家账号并返回账号 / 初始密码。
3. 招标方填写备注和截止时间，点击“推送专家评审”。
4. 后端将已添加的专家正式纳入本次评审任务，并进入 `专家评审中`。
5. 专家登录后直接进入唯一评审详情页。
6. 专家按投标单位逐家评审：
   - 查看 AI 审查后的待人工确认条目
   - 录入资格结论 / 评分
   - 填写建议
   - 上传图片附件
   - 必要时提出废标建议
7. 某专家提交后，进入只读状态。
8. 当所有专家都提交完成，或到达截止时间：
   - 自动提交未完成部分
   - 项目进入 `专家评审完成`
   - 临时专家账号自动清理
9. 管理端继续保留：
   - 专家评测结果查看
   - 统计对比
   - 导出报告
   - 已产生的待确认废标处理

## 4. 页面与展示规则

### 4.1 项目详情页 - 专家评测标签

- 没有任何专家提交过任何一家投标单位评审内容时：
  - 仅显示提示语
  - 不展示评分对比
  - 不展示统计表格
  - 不展示投标单位标签页内容
- 任意一位专家提交完全部投标单位评审内容后：
  - 展示完整专家评测内容
  - 展示专家提交情况
  - 展示评分对比
  - 展示平均分排行
  - 展示投标单位标签页
- 当有任意一位专家提交全部投标单位内容后，才展示完整统计区；只有局部提交时不展示综合排行。
- 专家提交情况至少包含：姓名、账号、提交状态、提交时间。
- 已确认废标公司在统计中显示 `已废标`，不显示平均分，并在主报告中保留占位行。

### 4.2 投标单位标签页

投标单位状态建议至少包含：

- `正常`
- `待确认废标`
- `已废标`
- `存在废标项`
- `已提交`（用于专家侧只读提示）

规则：

- 有专家提出废标建议但未确认时，显示 `待确认废标`。
- 管理员确认后，显示 `已废标`。
- 管理员选择 `继续展示` 后，该公司后续新的废标建议不再弹窗确认。
- 已确认废标公司在统计中显示 `已废标`，不显示平均分。

### 4.3 专家侧详情页

- 专家登录后直接进入当前唯一任务详情页。
- 顶部展示：
  - 项目名称
  - 评审截止时间
  - 剩余天数
- 顶部原文入口只展示当前公司对应的原文，不跳转任务列表。
- 页面按投标单位切换。
- 左侧为 AI 审查结果的要求分组列表。
- 右侧为评审内容区。
- 默认选中资格要求第一条；若不存在，则选中第一条可评项。
- 右上角提供原文展示按钮，样式和项目管理页一致。

- `ProjectAppService` 的项目详情、状态、绑定关系能力。

- `RoleCode.EXPERT`。
- `biz_requirement_item` 作为 AI 审查结果来源。
- 现有文件 / 项目 / 任务查询能力。

- 需要支持临时密码首次返回、后续仅保留重置能力。
- 需要支持专家评审后的只读态。
- 需要支持废标建议与管理员确认的联动。
- 需要支持按“项目 + 公司”永久生效的 `continue display` 规则。
- 需要支持项目进入专家评审后锁定 AI 审查结果。

### 5.3 需要新增

- 专家评审主表。
- 专家任务表。
- 专家评审结果表。
- 专家评审附件表。
- 项目 + 公司废标确认表。

- 专家评审控制器。
- 专家评审查询 / 导出接口。
- 后台任务：截止时间自动提交与账号清理。
- 项目详情页专家评测聚合查询接口。
- 专家侧当前任务详情接口。
- 管理端废标确认与继续展示接口。

### 6.6 评审对象来源

专家评审对象来自每个投标包下的 `biz_requirement_item`：

- 来源表：`biz_requirement_item`
- 评审范围为 AI 审查后仍需人工确认的条目
- 项目进入专家评审后，AI 审查结果锁定，不再增删改
- 每条条目都要进入专家评审结果，计入结果和统计

### 6.7 临时账号与密码规则

- 用户名建议由姓名 + 项目标识或随机后缀生成，避免重名冲突。
- 密码只生成一次并只在创建接口返回。
- 后续详情页仅展示账号，不回传密码明文。
- 重置密码接口只允许管理员或招标方发起，重置后仍按一次性展示规则处理。

### 6.8 废标确认规则

- 废标判断只对当前项目生效。
- 若当前公司已经处于 `CONTINUE_DISPLAY`，则新废标建议不再弹窗确认。
- 专家提交废标建议后，管理端显示 `待确认废标`。
- 管理端确认废标后，该公司从统计中剔除平均分展示，仅保留占位行。

## 7. 状态建议

### 7.1 项目状态

建议在现有 `workflowStatus` 基础上新增：

| 码 | 前端文案 | 判定 |
|----|----------|------|
| `EXPERT_REVIEWING` | 专家评审中 | 已推送专家评审，且未结束 |
| `EXPERT_REVIEW_SUCCESS` | 专家评审完成 | 所有专家都完成，或到达截止时间并自动提交 |
| `EXPERT_REVIEW_LOCKED` | 专家评审锁定 | 项目已结束，且不允许再推送 / 追加 / 改文件 |

### 7.2 专家任务状态

| 状态 | 说明 |
|------|------|
| `NOT_STARTED` | 未开始 |
| `RUNNING` | 评审中 |
| `READ_ONLY` | 已提交，只读 |
| `OVERDUE_SUBMITTED` | 超时自动提交 |
| `DISABLED` | 项目结束后账号不可登录 |
| `DELETED` | 项目删除后清理 |

### 7.3 公司状态

| 状态 | 说明 |
|------|------|
| `NORMAL` | 正常展示 |
| `PENDING_VETO` | 待确认废标 |
| `VETOED` | 已废标 |
| `CONTINUE_DISPLAY` | 已继续展示，后续废标不再弹窗 |

### 7.4 页面状态联动

- 项目 `AI审查完成`：显示“推送专家评审”。
- 项目 `专家评审中`：显示“追加推送专家”。
- 项目 `专家评审完成`：不显示推送入口，只读展示结果。
- 专家成员 `READ_ONLY`：已提交后不可再改。
- 专家成员 `DISABLED`：项目结束后不可登录。
- 公司 `PENDING_VETO`：展示废标确认弹窗入口。
- 公司 `VETOED`：仅显示已废标占位。

## 8. 接口建议

### 8.1 添加专家

`POST /api/projects/{projectId}/expert-reviews/members`

按专家姓名创建临时专家账号，返回账号和初始密码。

**请求体**

```json
{
  "displayName": "张三"
}
```

**返回**

```json
{
  "memberId": 1,
  "username": "zhangsan_7f3a",
  "displayName": "张三",
  "initialPassword": "A7k#29Pm"
}
```

### 8.2 推送专家评审

`POST /api/projects/{projectId}/expert-reviews/push`

推送时填写备注和截止时间，正式启动评审任务。

**请求体**

```json
{
  "deadlineAt": "2026-08-20T09:00:00Z",
  "pushMessage": "请按要求完成专家评审"
}
```

### 8.3 追加专家

`POST /api/projects/{projectId}/expert-reviews/append`

追加专家只传姓名，后端自动创建账号；备注和截止时间沿用首次推送，不允许修改。

**请求体**

```json
{
  "displayName": "李四"
}
```

### 8.4 专家当前任务

`GET /api/expert-review-tasks/current`

专家登录后直接返回当前唯一评审任务详情，不展示任务列表。

返回建议包含：

- 项目名称
- 评审截止时间
- 剩余天数
- 当前公司列表
- 当前公司下的待评审条目
- 当前专家是否只读
- 当前公司是否已废标 / 待确认废标 / 继续展示

### 8.5 项目专家评测详情

`GET /api/projects/{projectId}/expert-reviews`

返回：

- 专家提交情况
- 统计图表数据
- 投标单位标签页状态
- 待确认废标列表
- 导出所需数据

建议补充字段：

- `projectStatus`
- `hasAnyCompleteSubmission`
- `expertMembers`
- `companyTabs`
- `scoreCompareItems`
- `averageRanking`
- `vetoPendingItems`

### 8.6 保存评审

`POST /api/expert-review-tasks/{taskId}/items/{itemId}`

支持：

- 资格项结论
- 评分项填分
- 建议文本
- 图片附件
- 废标建议

建议支持幂等更新：同一专家、同一公司、同一条目重复保存时覆盖旧值。

### 8.7 提交专家评审

`POST /api/expert-review-tasks/{taskId}/submit`

提交后进入只读。

提交后建议返回：

- 提交时间
- 是否超时
- 当前项目是否因此进入完成判断

### 8.8 管理端废标确认

`POST /api/projects/{projectId}/expert-reviews/companies/{companyId}/veto/confirm`

建议返回：

- 公司状态
- 是否还存在其他待确认废标
- 是否影响统计展示

### 8.9 管理端继续展示

`POST /api/projects/{projectId}/expert-reviews/companies/{companyId}/veto/continue`

建议返回：

- 公司 display_mode
- 是否永久生效

### 8.10 导出报告

`GET /api/projects/{projectId}/expert-reviews/export`

导出表格文件：

- 主报告包含所有投标单位
- 已确认废标单位保留“已废标”占位行
- 废标原因单独成页
- 导出时保留专家打分对比和公司平均分排行
- 当前已落地为 xlsx 附件，包含 `概览`、`专家提交`、`投标单位排行`、`专家评分对比`、`待确认废标` sheet
- 若项目尚无专家评审记录，导出接口返回 404

## 9. 边界处理

- 首次推送后，项目下招标文件与投标文件的上传、替换、删除、重新解析、重新审查全部锁定。
- 专家评审完成后，未提交单位被锁定。
- 专家评审完成后，不再允许推送或追加专家。
- 项目删除时，相关评审数据和临时专家账号一起清理。
- 项目结束后，管理端仍可查看专家评测结果和导出报告。
- 专家账号清理后，无法再登录。
- 附件仅支持图片格式。
- 评分不能超过该项满分。
- 资格项选择“不符合”时，先确认是否废标；确认后该专家直接结束当前项目评审，不影响其他专家。
- 所有专家都已完成后，项目结束并自动清理临时专家账号。
- 项目删除后，专家评审主表、结果表、附件、临时账号一并清理。
- 专家账号清理后，当前项目下不能再登录，但历史评审数据仍供管理端查看。

## 10. API 文档维护约定

- 专家评审 API 文档：`docs/API-专家评审.md`。
- 每新增或变更一个专家评审接口，都同步更新 `docs/API-专家评审.md`。
- `docs/API.md` 总索引需要保留“专家评审”分册入口。
- 文档格式参照 `docs/API-文件与标包.md`、`docs/API-招标解析.md` 和 `docs/API-投标模拟审核.md`。
- 后续保存、提交、废标确认、项目端统计、导出等接口落地时，先把“后续接口规划”改成正式接口说明。
