## 浏览器 CORS（前端页面调接口必看）

- 前端页面在 `http://127.0.0.1:5186`，接口在 `http://192.168.8.83`，属于**跨域**。
- 浏览器会先发 OPTIONS 预检；后端必须返回 `Access-Control-Allow-Origin` 等头，否则请求被拦截。
- Apifox / curl **不检查 CORS**，所以会出现「工具能通、浏览器不通」。
- 后端已配置允许 Origin：`http://127.0.0.1:5186`、`http://localhost:5186`（可用环境变量 `CORS_ALLOWED_ORIGINS` 追加）。
- 改前端端口或加新域名后，需同步改配置并**重启后端**。

## 统一响应与错误码

```json
{ "code": 0, "message": "ok", "data": {} }
```

| code | 含义 |
|------|------|
| 0 | 成功 |
| 40000 | 请求参数错误 |
| 40100 | 未登录或登录已失效 |
| 40300 | 无权限 / 强制改密未完成 |
| 40400 | 资源不存在（含跨组织故意模糊） |
| 40900 | 资源冲突 |
| 50000 | 系统错误 |

前端判断：优先看 `code === 0`。
